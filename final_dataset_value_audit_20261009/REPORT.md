**Verdict: do not use FINAL_DATASET unchanged for a final CNN, DNN, or CLDNN experiment.** The numeric files are readable and structurally consistent, but there are confirmed duplicate recordings, synchronous zero intervals, major recording-length differences, and strong opportunities for models to learn acquisition/source differences. These findings do not imply that all recordings should be discarded.

This audit inspected the contents of FINAL_DATASET only as its input. It did not read the existing dataset_audit directory, project code, documentation, or the linked source websites. Reports and scripts in this new output directory were generated by the audit; source data were not modified. Source cohort sizes and native rates below come from the user, not independent verification.

**Coverage and checks that passed**

- 232 subject folders: 116 Alzehiemers and 116 Healthy. These are folder counts, not verified unique people.
- 4,408 channel text files; 5,308,108,591 bytes of signal text; every one of the 382,017,458 numeric values was parsed and included in the numerical scan.
- The only other files found were three macOS .DS_Store files, which were inventoried and excluded from EEG analysis.
- Every subject has the same 19 channel names: C3, C4, Cz, F3, F4, F7, F8, Fp1, Fp2, Fz, O1, O2, P3, P4, Pz, T3, T4, T5, T6.
- No parsing errors, NaNs, infinities, empty channels, wholly constant channels, or within-subject channel-length mismatches.
- Every signal file has one physical line per parsed numeric value; no comment markers or extra nonnumeric header rows were found.
- Matching channel lengths establish compatible array shapes, not proof of correct electrode naming or acquisition-time alignment.

**Confirmed duplication: must resolve before splitting**

Alzehiemers/eyes-closed/patient76, patient77, patient78, patient79, and patient80 contain identical recordings. All 19 corresponding files are byte-for-byte identical, and every numeric sample is identical. Each channel has 1,024 samples. This is 19 groups of five identical files, or 76 redundant channel-file copies relative to one retained recording.

There are at most 228 distinct full-recording arrays: 112 Alzheimer’s and 116 Healthy after collapsing this group. This does not establish 228 unique biological subjects. Restore the intended originals if these were accidentally copied; otherwise keep one representative or explicitly treat the entire group as a single recording/subject group. Do not let copies appear in different train/validation/test partitions. The audit did not delete them.

No other exact full-channel numeric duplicates were detected, including across class labels. Same-channel scaled-copy screening and full-overlap verification found no additional candidates beyond this group. Exact 1,024-sample blocks at 1,024-sample-aligned offsets likewise only exposed this group. These checks do not exclude shifted excerpts, re-filtered copies, arbitrary temporal overlap, or multiple recordings of the same person.

**Recording length and source confounding: must address**

The following groups are directly observable from folder indices and signal lengths. Their correspondence to the three source datasets is suggested by the matching cohort counts and numerical characteristics, but is not documented inside the signal files.

| Alzehiemers patient1–36 | 36 | 39,309–165,261 | 94.62 |
| Alzehiemers patient37–116 | 80 | 1,024 | 8.26 |

92 subjects have just 1,024 samples per channel. If those exported files are still at 128 Hz, each contains eight seconds. The other 140 have 39,309–348,801 samples per channel. Confirm whether the short recordings are intentionally selected epochs or an incomplete export; the files alone cannot decide that. Do not manufacture more independent data by duplicating, interpolating, or heavily overlapping these eight-second records.

The rule “predict Alzheimer’s if length is 1,024 samples, otherwise Healthy” matches 184/232 labels (79.31%) in this folder. This is a descriptive shortcut calculation, not a cross-validated trained-model result. Padding lengths or masks can expose the same shortcut to a network.

Although folders are class-balanced, Alzheimer’s accounts for 3,845,555 channel-timepoints (19.13%) and Healthy for 16,260,627 (80.87%). Each timepoint has 19 channel values. Before any resampling or rejection, nonoverlapping 1,024-sample windows produce 3,736 Alzheimer’s windows and 15,828 Healthy windows, discarding short tails. These are sample counts, not comparable durations until sampling rates are verified.

Using the user-provided source class counts, predicting each source’s majority label would match (36 + 80 + 75)/232 = 82.33% of labels before deduplication. This is a theoretical source-only shortcut, not proof that a trained network achieves it. The Healthy-only source especially makes source and outcome dependent. Filtering and normalization cannot by themselves establish that this confounding is gone.

Prefer an initial primary evaluation on sources containing both classes, with source-aware, subject-grouped partitions and results reported separately for each source. Treat the Healthy-only source as supplemental data or an additional specificity assessment; it cannot independently establish Alzheimer’s sensitivity or full binary performance. Cross-source evaluation between datasets containing both classes is useful once identities, preprocessing, and rates are verified.

**Confirmed zero intervals and signal-quality review flags**

- 162 intervals across 35 subjects have all 19 channels simultaneously equal to zero, totaling 6,202 channel-timepoints. These are suspect gaps/padding or acquisition/export artifacts; their origin cannot be determined here. See simultaneous_zero_intervals.csv for exact zero-based, end-exclusive positions.
- Example: Alzehiemers patient22 has 130 initial zero samples in every channel. Remove or mask invalid segments consistently across channels after confirming their meaning; avoid filtering across gaps or concatenating separated clean stretches as if continuous.
- Across individual channels there are 3,069 constant runs of at least 16 samples. Many are the same simultaneous gaps counted once per channel; they are not 3,069 independent recording failures.
- Stored values span -5,386.59488 to +6,678.90281. The maximum one-sample jump is 7,611.9978 in Alzehiemers patient27/T4.txt. Units are absent, so these numbers alone do not justify a physiological amplitude cutoff. Review the locations and surrounding waveforms after establishing units.
- 420 within-subject channel pairs across 31 subjects have absolute Pearson correlation above 0.98. Alzehiemers patient31 has 129 such pairs; its C3–T3 correlation is 0.998993. These may reflect dominant common artifact, reference effects, or other shared activity. They are review flags, not proof of duplicated electrodes, and should be checked after appropriate signal cleaning/reference handling.
- A robust amplitude screen found 1,144,822 channel-values more than 10 × 1.4826 × MAD away from the channel median, across 119 subjects. This is a heuristic, not a validated artifact annotation or a count of unusable samples.
- 5,945 channel windows were flagged by the screening rules in audit.py: nonoverlapping 1,024-sample blocks that are constant, have peak-to-peak greater than 20 × 1.4826 × whole-channel MAD, or have a mean displaced by more than 10 × 1.4826 × MAD. These windows overlap across channels. Tail remainders were included in full-channel statistics but not this fixed-block screen. Do not automatically delete every flagged window.
- The 1,024-sample groups have much more repeated adjacent values (group median fractions approximately 9.29% for Alzheimer’s and 7.23% for Healthy), versus approximately 0–0.096% in the longer groups. This is consistent with different quantization/processing and is another source signature; it is not alone evidence of corruption.

The tiny initial values in Healthy patient80/Fp1 are not evidence that the whole file uses a different physical unit: the first 512-sample standard deviation is 10.85 and a middle 512-sample interval is 7.23. Initial transients must not be used to infer a whole-recording conversion factor.

**Information the folder cannot verify**

The plain channel files contain no per-recording sampling-rate declaration, unit, source ID, original subject ID, reference/montage description, timestamps, preprocessing history, or diagnostic metadata. A class directory supplies an assigned label, not independent evidence that the diagnosis is correct. The source-native rates supplied by the user do not prove the rate of these exported arrays: prior resampling may already have occurred. Likewise, matching channel filenames do not prove a consistent physical montage or reference.

Restore a manifest with at least source_dataset, original_subject_id, recording_id, class, actual_file_sampling_rate_hz, physical_unit, ordered_channel_names, reference, and preprocessing/export history. Track duplicate groups and clean intervals. The local IDs patient1, patient2, etc. recur under both class directories, so use a globally unique identity derived from provenance; do not group or join solely on the numeric patient suffix.

**Practical preparation for CNN, DNN, and CLDNN**

1. Resolve the patient76–80 duplicates and confirm the short exports. Recover provenance and actual file rates/units first. Keep the originals intact.
2. Establish a fixed channel order and consistent unit/reference treatment. Do not normalize each source using its label or use source identity as a predictor.
3. Once actual rates are known, a common 128 Hz representation is a reasonable starting design for these user-described 128/500 Hz sources. Apply proper anti-alias filtering when converting 500 Hz to 128 Hz; do not simply take every fourth sample (that yields 125 Hz). Do not downsample files that are already at 128 Hz. If the actual rates differ from the supplied native rates, revise the plan accordingly.
4. Choose a common EEG passband within the shared supported bandwidth and inspect line noise before deciding on a notch. A candidate starting passband is 0.5–40 Hz, to be validated for this experiment. Apply filtering to continuous valid stretches with appropriate boundary handling; short eight-second records leave little room for filter transients. Document any discarded edge samples. No fixed filter setting can be certified from the current metadata-free exports.
5. Review synchronous zeros, abrupt jumps, large robust outliers, and highly correlated channels. Reject or repair suspect intervals using criteria fixed without looking at test outcomes. Record retained duration per subject and source; ensure cleaning does not silently remove one class disproportionately.
6. Split by original person and duplicate group BEFORE generating training windows, augmentations, or fitted preprocessing statistics. Keep all sessions and windows of each person in one partition. Fit any learned scaler, imputer, feature selection, or artifact model on training data only. Use the same partitions for all three architectures.
7. Use fixed-duration windows after rate harmonization. For example, four seconds at 128 Hz gives 19 × 512 values. This is a design example, not a validated optimum: artifact rejection and filter margins may leave fewer than two usable windows in an eight-second recording. Cap or balance windows per subject so long Healthy recordings do not dominate. Avoid subject length, padding extent, filenames, and source-dependent export formats as model inputs.
8. CNN: use ordered channel × time arrays. DNN: a raw four-second window flattens to 9,728 inputs, so keep capacity modest and regularize given at most 228 distinct recording arrays. CLDNN: preserve genuine within-subject temporal ordering and keep any context sequence within a valid continuous recording; do not concatenate subjects or bridge gaps to create longer sequences. All three can consume processed time-domain EEG without manually engineered frequency features.
9. Report subject-level predictions, balanced accuracy, sensitivity, specificity, AUROC where both classes are present, and uncertainty. Aggregate window predictions per subject; do not treat many correlated windows as independent test subjects. Compare against simple baselines and inspect per-source performance. Choose thresholds and hyperparameters using validation data, then evaluate the held-out test set once.

**Artifacts and limits**

channel_statistics.csv covers every channel; subject_statistics.csv covers every subject; subject_review_queue.csv combines action flags. summary.json and followup_summary.json contain machine-readable coverage and findings. Duplicate reports identify full files and matching blocks. audit_overview.png visualizes the principal length/scale mismatch and two signal examples. Reproducible scripts are audit.py, followup.py, and report.py; they write into this report directory and read no other project inputs.

Frequency summaries in channel_statistics.csv are in cycles per sample because true file rates are unverified. They must not be interpreted as physiological EEG band powers or evidence of a particular mains frequency. The spectral screening uses overlapping Hann-windowed blocks covering the full-block portion of each recording; the universal every-value guarantee applies to parsing, finite-value checks, descriptive channel statistics, derivatives, and exact duplication hashes, not every conceivable signal-quality test.

This audit establishes numerical integrity and specific problems, not clinical label validity, biological subject independence, or artifact-free EEG. After fixing confirmed issues and documenting the missing acquisition information, the data may support exploratory model development. A high score from the current mixed folder would not by itself demonstrate Alzheimer’s discrimination.
